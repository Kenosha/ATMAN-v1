# Repository history

ATMAN v1 was extracted into a separate repository with **1,170 retained historical commits**. Original author and committer names and dates are preserved; commit hashes changed when the history was filtered.

The retained material includes `ATMANpy`, broadcast-video scripts at the repository root, broadcast ball-SVM work, and selected research and video-production notes. The extraction isolates the broadcast processing, analysis, and visualization workflows. A few descriptions of mixed-scope commits were generalized to match that retained scope.

The original ATMAN repository was left untouched. Subsequent commits make this checkout usable on its own: documentation, a small public sample, demonstration commands, an isolated full-pipeline runner, compatibility fixes, tests, and the three README animations. Large local feature archives, full videos, recovered model assets, and generated test outputs remain outside Git.

For current usage, start with the [README](../README.md) and [running instructions](RUNNING.md). Historical notes are collected in [the archive](archive/README.md). The project-wide license has not yet been selected; see [licensing status](LICENSING.md).
