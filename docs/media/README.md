# README demonstrations

These three GIFs reproduce the full original ATMAN animations used on [atman-tennis.com](https://atman-tennis.com) and the personal website. The original videos were published through Cloudflare Stream. They illustrate the historical project; they are separate from the newly tested four-minute run.

| File | Demonstration | Duration | Size |
| --- | --- | --- | --- |
| [recognition.gif](recognition.gif) | Court, player and ball recognition | 47.9 s | 6.68 MiB |
| [query.gif](query.gif) | Filtering and aggregation syntax | 20.4 s | 3.25 MiB |
| [visualization.gif](visualization.gif) | 3D visualization engine | 31.3 s | 7.71 MiB |

The exports keep the full sequence at its native 640×360 resolution, use 10 frames per second and a 128-color palette, and loop continuously. All frames were decoded and checked. Source identifiers and SHA-256 fingerprints are in [provenance.json](provenance.json).

The README embeds these files with relative image links, so the animations are served by GitHub. The Cloudflare player is not needed to display them. A visitor's GitHub motion settings can pause autoplay.
